# I18N Guide (Manager App)

This document explains the generic translation workflow for `apps/manager`: how to add keys, use them in code, and sync with Crowdin.

## Stack

- `i18next` + `react-i18next` for runtime translations.
- `@ensdomains/vite-plugin-i18next-loader` to load locale files from `locales/`.
- `@crowdin/cli` for source/translation sync.

## Core Layout

```text
apps/manager/
  crowdin.yml
  locales/
    en/
      <namespace>.json
  src/
    lib/
      i18n.ts
    routes/
      __root.tsx
```

From repo root:

```bash

```

From repo root:


No production build is required for translation work during development.

## Add Translations for Any Feature

1. Choose a namespace for your feature (example: `wallet`, `settings`, `profile`).
2. Add/update source keys in:

```text
apps/manager/locales/en/<namespace>.json
```

3. In UI code, use that namespace:

```ts
import { useTranslation } from 'react-i18next'

const { t } = useTranslation('<namespace>')
```

4. Render strings with `t(...)`:

```tsx
<span>{t('section.title')}</span>
```

5. Use interpolation for dynamic values:

```ts
t('pagination.range', { start, end, total })
```

6. Use i18next plural keys for counts:

```json
{
  "itemsCount_one": "{{count}} item",
  "itemsCount_other": "{{count}} items"
}
```

```ts
t('itemsCount', { count })
```

## New Namespace Checklist

When creating a new namespace file:

1. Add `locales/en/<namespace>.json`.
2. Add a matching entry in `apps/manager/crowdin.yml`:
   `source: /locales/en/<namespace>.json`
   `translation: /locales/%two_letters_code%/<namespace>.json`
3. Ensure the namespace is included in `src/lib/i18n.ts` (`ns` list).

## Language Switching

Language changes should call:

```ts
i18n.changeLanguage(languageCode)
```

Supported languages shown in UI are derived from loaded locale resources.

```bash

```

```text
apps/manager/locales/<two_letter_code>/<namespace>.json
```

## Troubleshooting

Missing translation in UI:
- Verify namespace and key path match exactly.
- Verify the key exists in `locales/en/<namespace>.json`.
- Verify `src/lib/i18n.ts` is loaded via `src/routes/__root.tsx`.

Crowdin auth/config errors:
- Verify `CROWDIN_PERSONAL_TOKEN` is set.
- Run `pnpm --filter manager run i18n:lint` and fix reported config issues.
